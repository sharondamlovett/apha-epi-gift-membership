# APHA Gift Membership Database

Created and managed by Dr. Sharonda Lovett at sharonda.lovett.apha [at] gmail.com

Searchable database of current APHA members seeking financial support for a 1-year APHA membership waiver. Prospective donors can review the profiles of prospective recipients, identify which recipient(s) they wish to gift to, and contact APHA staff directly at 1-877-396-APHA (2742) weekdays between 9am–5pm Eastern Time to coordinate payment. All donors and recipients will receive an email confirmation of the transaction recipient/processing of the APHA membership from APHA staff. Please do not attempt to exchange payment without APHA staff. Learn more about the APHA Gift Membership Program: https://www.apha.org/membership/gift-membership
